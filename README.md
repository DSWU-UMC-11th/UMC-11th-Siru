# UMC-11th-Siru

UMC 11기 **Siru**의 주차별 학습 내용과 미션을 기록하는 저장소입니다.

<br>

### 📂 과제 관리

과제는 `week0`부터 `week10`까지 siru 브랜치의 주차별 폴더에서 관리합니다.

<br>

### 💡 커밋 컨벤션

- `CHORE`: 설정 변경, 패키지 설치, 내부 파일 수정

- `FEAT`: 새로운 기능 추가

- `FIX`: 버그 및 오류 수정

- `DOCS`: README 등 문서 수정

- `REFACTOR`: 기능 변경 없는 코드 리팩터링

- `TEST`: 테스트 코드 추가 및 수정
